Minimal navigation reduced cognitive overload
Interactive destination sections improved engagement

Goal

Design and develop a centralized and user-friendly platform that streamlines donor management, blood inventory tracking, and emergency blood request processing while improving communication between donors, admins, and healthcare providers.

Measurable Impact

50% Reduction in blood request processing time
93% Accuracy in inventory tracking during testing
40% Faster donor registration process
Real-time Improved emergency response coordination through notifications

Dashboard-based interface simplified inventory and request management

Multi-role access created smoother workflows for donors, admins, and hospitals
Real-time notifications improved emergency communication efficiency

Druk Brain Scan

An AI-powered healthcare platform for clear and accessible brain tumour detection.

Project Overview

Druk Brain Scan is an AI-powered healthcare platform designed to assist in brain tumour detection using the VGG16 deep learning model. The project focused on creating an intuitive and accessible user experience that helps healthcare professionals upload scans, view AI-generated predictions, and interpret clinical results easily without requiring technical AI knowledge.

Problem Statement

Healthcare professionals often struggle to interpret complex AI-generated medical outputs due to technical interfaces and unclear visualizations. Existing systems lack user-friendly workflows that simplify AI-assisted diagnosis for non-technical users.

Goal

Design a clear and efficient medical interface that enables healthcare professionals to upload MRI scans, receive AI-powered tumour detection results, and understand predictions confidently through intuitive visual feedback and simplified workflows.

Measurable Impact

95.8% Test accuracy achieved using the VGG16 model
87% Users interpreted AI outputs without assistance
41% Reduction in scan result review time during testing
Improved Confidence in AI-assisted diagnosis

UX Decision Rationale

Simplified AI result visualization made predictions easier to interpret
Clean medical dashboard reduced cognitive overload during scan analysis
Color-coded confidence indicators improved prediction understanding
Step-by-step upload workflow minimized scan submission errors

User Personas

User Research Insights

Pain Points

User Needs
